# League Client (LCU) API Reference

Friendly Markdown rebuild of `lcuapi.txt` (Swagger export, client **8.24**).

**1033 endpoints** across **99 plugin namespaces**. Endpoints are grouped by namespace (the first path segment) — click one to open its reference.

> Base URL: `https://127.0.0.1:{port}` — port and an HTTP Basic auth password come from the client's lockfile. All calls use the `riot:{password}` credentials over HTTPS (self-signed cert).
