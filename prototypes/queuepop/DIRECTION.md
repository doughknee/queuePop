# QueuePop / one home, three worlds

Scope: standalone, interactive visual concept. No production UI, Python, game client, live statistics, notifications, or backend changes.

Shared palette: charcoal #141618, warm white #EEEAE1, muted gold #D3B981, grey #A5A6A6, quiet sage #A7BCAB. Retain the original Queue Sigil; Segoe UI provides familiar desktop controls. Shared top bar, game links, companion, saved plans, focus styles, and confirmation language.

League: midnight blue #081A24, luminous blue #93D8E5, antique gold #C8AA6E. Cinzel for ceremonial headings, Marcellus for softer editorial moments, Segoe UI for practical detail. Sweeping champion splash, a large left-aligned title, restrained inlaid rules, meaningful champion selection. Interior pages retain art beside legible planning information.

TFT: plum #211D36, violet #B9A0ED, honey #F5CD74, seafoam #9BD6C0. Rounded, heavy Trebuchet headings. A friendly illustrated world and a tactile hexagonal team board, compact bench, and readable side notes. Deliberately distinct from League's ceremonial portrait.

Composition:
```
Shared:  QueuePop | Home · League · TFT · Deadlock | Companion
Home:    greeting + saved plan / three generous illustrated world entrances
League:  game navigation / cinematic champion + left title / plan + recent match
TFT:     game navigation / playful landscape / composition board + strategy notes
```

Review before implementation: a second stat dashboard would repeat the rejected first Deadlock pass. Prefer game artwork, character choice, and playable planning tools; statistics support the task. Shared brand is intentionally quiet so the game worlds can be distinct. No popup menus or modals. Deadlock remains approved and intact; a generated HTML bridge swaps only its global masthead and reuses its original local scripts/styles/assets.

Fixture data is illustrative and intentionally not represented as current patch advice. TFT formations use familiar champion portraits to demonstrate the planner, not a claimed live set roster.
