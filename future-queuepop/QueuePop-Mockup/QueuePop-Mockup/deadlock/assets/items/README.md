# Deadlock item artwork

The 12 locally stored WebP icons are Valve Deadlock item artwork, obtained through the community Deadlock API asset metadata at https://api.deadlock-api.com/v1/assets/items on 2026-10-12. `sources.json` records each exact source URL and local filename. These are existing game assets, not newly authored QueuePop artwork.

The local frontend uses no runtime API calls. Item names, sample combinations, and notes illustrate the design and interaction; they are not live build recommendations. No item prices or numeric game effects are represented. Confirm appropriate asset permissions before public distribution.
