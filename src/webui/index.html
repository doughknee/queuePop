Discord Notifications (optional)

How to set this up
  1. In Discord: Server Settings → Integrations → Webhooks → New Webhook.
  2. Pick a channel, click Copy Webhook URL, and paste it above.
  3. Make sure mobile notifications are on for that channel.
  4. Optional @mention: enable Developer Mode (User Settings → Advanced), then right-click your name → Copy User ID.

No Discord? Use the Phone Companion above instead.
