# Sandbox asset sources

The sandbox uses a small Set 13 roster, not a current meta or complete game simulator. Champion names, costs, traits, stats, ability names and paraphrased ability summaries are taken from the Set 13 entry of CommunityDragon TFT data retrieved October 13, 2026. Item descriptions are broad summaries; no live balance numbers are claimed.

- Data: https://raw.communitydragon.org/latest/cdragon/tft/en_us.json
- Champion and item artwork: corresponding `squareIcon` and `icon` paths in that data, served under https://raw.communitydragon.org/latest/game/ with `.tex` converted to `.png`. Each local image is named for its actual champion/item.
- Avarosa arena background: Riot Games, [TFT: New Arena Skins](https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/tft-new-arena-skins/).
- Background image: https://cmsassets.rgpub.io/sanity/images/dsfx7636/news_live/c4cb7065f6007b32d6287ecee82b8d00a6381680-951x535.jpg

All game imagery belongs to Riot Games. This is an independent, local fan prototype. The arena geometry and interactive interface are authored in this project. Earlier imported portraits in the lower sample comp list are preserved separately and remain illustrative.


### Connected Set 13 guides
Riot's Into the Arcane overview confirms the set identity and included champion/trait names: https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/into-the-arcane-overview/ . Sett's extra Pit Fighter trait from the imported sample was removed to match Rebel/Bruiser. The three guide boards, positioning lessons and item-holder examples are original practice content for this limited roster, not sourced competitive tier lists or measured performance recommendations.
