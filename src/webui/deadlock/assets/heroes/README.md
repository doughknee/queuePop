# Hero portrait sources

Deadlock character artwork belongs to Valve. These six portraits are included for this local, unofficial frontend design study.

Retrieved from the community Deadlock API on October 12, 2026:

- API documentation: https://api.deadlock-api.com/docs
- Metadata endpoint: https://api.deadlock-api.com/v1/assets/heroes
- Exact portrait URLs: `sources.json`

Portrait files are unchanged WebP assets, stored locally so the preview has no runtime API or image-host dependency. They replace the earlier placeholder glyphs. This is an asset download, not a game/account integration.
